# Домашна 3

## Задача: N кралици (N-Queens Problem)

Целта на задачата е да се постават N кралици на шаховска табла со димензии N × N, така што ниту една кралица да не може да нападне друга.

За решавање на проблемот користев рекурзија и backtracking.

На почетокот се внесува бројот N и се креира табла со N редици и N колони. Потоа, со рекурзивна функција се обидувам да поставам по една кралица во секој ред.

Пред да поставам кралица, проверувам дали избраното поле е безбедно. Проверувам дали во истата колона или во некоја од двете дијагонали над полето има веќе поставена кралица.

Доколку полето е безбедно, поставувам кралица и рекурзивно продолжувам со следниот ред. Ако не се добие решение, ја отстранувам кралицата од претходно избраното поле и продолжувам со испробување на другите можности.

Кога ќе се постават сите N кралици, се добива едно валидно решение и се печати таблата.

На овој начин програмата ги пронаоѓа и ги печати сите можни решенија за внесената вредност на N.

## Пример за N = 4

За табла со димензии 4 × 4 постојат две можни решенија.

**Решение 1**

|   | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **1** | - | Q | - | - |
| **2** | - | - | - | Q |
| **3** | Q | - | - | - |
| **4** | - | - | Q | - |

**Решение 2**

|   | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **1** | - | - | Q | - |
| **2** | Q | - | - | - |
| **3** | - | - | - | Q |
| **4** | - | Q | - | - |

**Ознаки:**
- `Q` – поле на кое е поставена кралица.
- `-` – празно поле.
